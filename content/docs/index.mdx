Nepal Dev Verse holds the documentation for packages and projects by Nepalese developers all over the world, as part of
[nepal-dev.com](https://nepal-dev.com). It documents itself the same way, as the project `docs`.

## How every package and project is organised

Each one lives at its own address, `/<slug>`, and has the same shape:

| Address | What it holds |
|---|---|
| `/<slug>` | The overview: what it is, its versions and where to go next |
| `/<slug>/use/…` | **Use**: docs for people using it, one set per release |
| `/<slug>/use/dev/…` | Work in progress on the default branch, not released yet |
| `/<slug>/use/latest/…` | Always the latest release |
| `/<slug>/maintain/…` | **Maintain**: docs for the people who look after it |

Every page states the version it documents. Add `.md` to any page's address for its Markdown,
or read [`/llms.txt`](/llms.txt) for an index of every page.

## This site

Nepal Dev Verse Docs has no Use track yet. Its **Maintain** track holds the decisions and design documents
behind it: start at the [maintainer documentation map](./maintain/index.mdx).
