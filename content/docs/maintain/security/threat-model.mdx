## Current attack surface

The site is static pages built from `content/`, one folder per package or project at
`/<slug>/…`, served with their Markdown, `llms.txt` / `llms-full.txt`, share images and `static.json`, plus Algolia
search ([`../architecture/system.mdx`](../architecture/system.mdx)). Every page is prerendered
(Cache Components, ADR-0016); none reads cookies or headers. There is no sign-in, no database
and no user input beyond the search box. The home page's Private projects group is public
static markup listing three invented projects from `src/components/home/private-projects.ts`
(ADR-0017 decision 4); it holds no private data.

| Surface | Present | Detail |
|---|---|---|
| Authentication / sessions | No | — |
| Route handlers | Yes | Markdown, `llms.txt`, `llms-full.txt`, share images, `static.json`, `robots.txt`, `sitemap.xml`, the manifest, the Apple icon, the Archify diagrams under `/diagrams/` — all public, all static ([`../api/content-routes.mdx`](../api/content-routes.mdx), [`../api/crawler-routes.mdx`](../api/crawler-routes.mdx)) |
| User input of any kind | Yes | The search query, sent from the browser straight to Algolia; the `Accept` header, read by `src/proxy.ts`; the request's path, compared by `src/proxy.ts` with a fixed list and never echoed |
| Database or persistence | No | Content is files; the search index is a build output |
| Files / uploads | No uploads | Archify diagrams in `diagrams/`: generated script, committed by the owner, served with the site shell's added script and style, run in a sandboxed frame and served with a CSP `sandbox` header. The frame sends the page one message, its height, which the page takes only from that frame's window and only as a number from 120 to 4000 (ADR-0011, ADR-0022, [`../api/content-routes.mdx`](../api/content-routes.mdx)) |
| Secrets / environment variables | Yes | Listed in [`secrets.mdx`](./secrets.mdx); in Vercel's Production environment, the write key marked *Sensitive* (ADR-0042) |
| Third-party integrations | Yes | Algolia (search). GitHub serves the avatar in each profile chip to the reader's browser, without a referrer (ADR-0020). The page actions' Open in ChatGPT, Claude, Cursor and Scira links, on docs pages and the home page, send a public page's URL to that service when the reader clicks one. The fonts are fetched by `next/font` at build time and served from the site's own origin |
| Build and deploy | Yes | Vercel builds `main` only, with `bun run build`, so a push to `main` publishes the site and the search index; other branches get no deployment, and a fork deployment someone authorizes or a CLI deploy builds with no variables, so it cannot publish (`vercel.json`, ADR-0042, ADR-0043) |
| Logging / audit trail | No | The sync script prints a record count |

Each ADR that adds a surface updates this table in the same change.

## Assets to protect

| # | Asset | Harm if exposed or corrupted |
|---|---|---|
| A1 | Private project documentation | Architecture, internal APIs, hostnames or client names published and crawled; cannot be recalled |
| A2 | `ALGOLIA_WRITE_KEY` | Anyone can replace or wipe the search index, or plant pages in it |
| A3 | Integrity of published package docs | A wrong install command or a tampered example is copied into other people's projects |
| A4 | Unfixed security findings | Published in these maintainer pages before the fix, they are an attack plan; they go to the owner, not into these pages (ADR-0002) |
| A5 | The owner's identity and reputation | Pages or search results that appear to be the owner's but are not |

## Adversaries to design for

| Adversary | Goal | Typical path |
|---|---|---|
| Anyone on the internet | Read private documentation | The site, `llms-full.txt`, `static.json`, or the search index with the public search-only key |
| Crawlers and LLM scrapers | Collect everything published | `llms.txt` / `llms-full.txt`, the Markdown routes — intended for public content, indiscriminate for private |
| Someone holding a leaked write key | Deface or poison search | Direct writes to the Algolia index |
| A malicious contribution or dependency | Tamper with content or the build | A changed example, a compromised package in the build |

## Trust boundaries

Crossed today, each in [`../dfd/system.mdx`](../dfd/system.mdx):

| Boundary | Carries |
|---|---|
| GitHub ↔ Vercel build | A full clone of `main` on every push to it (ADR-0042) |
| Vercel build ↔ Algolia | Every page's search record, with the write key |
| Browser ↔ Algolia | Search queries and results, with the search-only key |
| Browser ↔ GitHub | Avatar requests for profile chips: the reader's IP address and user agent, no page address |
| Browser ↔ Vercel Analytics | Page views without query strings and Web Vitals, on the site's own origin, no cookie (ADR-0041) |
| Browser ↔ Google Analytics | Cookieless pings before consent, hits with the `_ga` client ID after *Allow*; gtag.js loaded live from Google (ADR-0041) |
| Site ↔ public | Every page on every surface |

Anticipated, each documented by the ADR that introduces it:

| Boundary | Will carry |
|---|---|
| Site ↔ authentication provider | Reader identity, if private docs are served from this site |

## Accepted risks

| Risk | Why accepted | Guard |
|---|---|---|
| GitHub sees which IP addresses load which avatars, so it can tell that someone read a page naming that user (A5 for readers' privacy). | The owner chose live avatars over a committed copy or an image proxy (ADR-0020). | `referrerpolicy="no-referrer"`; avatars load lazily, only when the chip is near the viewport. |
| The avatar is whatever the GitHub account sets, shown on the site. | It is that person's own profile picture, shown at 20px as decoration. | The chip's name and link come from the page, not from GitHub. |
| A future Archify release adds a network call or an external resource to the generated diagrams; the sandbox does not block outgoing requests. | Diagrams are made with Archify by the owner's standing choice; Archify 3.2.0 makes none. | Each upgrade needs the owner's yes, and its HTML is scanned before it is published (checklist, Archify). |
| The private projects list (`src/components/home/private-projects.ts`) is the one place in code where a private project's name is typed. Someone may later replace an invented name with a real client's, publishing it on the home page and to crawlers (A1). | The owner chose to show invented private projects on the live site (ADR-0017). | The file's comment says only invented names belong there until the private-documentation ADR; a real name there breaks invariant 1. The list is never sent to search, `llms.txt` or `static.json`. |
| Google receives a cookieless ping with each reader's IP address and user agent before they choose, under Consent Mode v2 advanced; some EU authorities treat that as needing consent too (A5). | The owner chose advanced mode for fuller, modelled reports (ADR-0041). | No cookie and no client ID before *Allow*; ads signals always denied; Google signals off; IP not kept by GA4; Global Privacy Control declines. |
| gtag.js and Vercel's scripts are loaded live and unpinned, so a change on their side runs on every page. | Both are the vendors' own scripts, the only way they are offered (ADR-0041). | No other tag can be added without an ADR; no Tag Manager. |
| Each page's address and title reach Vercel and Google. | Every page is public today (ADR-0041). | The private-documentation ADR must keep analytics off private pages. |
| Anyone who can push to `main`, or change the Vercel project, publishes to the site and the search index at once; no preview stands between (A1, A3). | The owner chose a direct production build with no previews (ADR-0042). | Agents never commit or push (`AGENTS.md` §3); the owner reviews every change; GitHub branch protection on `main` is the owner's to set. |
| A compromised dependency runs during the Vercel build with `ALGOLIA_WRITE_KEY` in its environment (A2, A3). | The same exposure as the owner's machine, now on every push to `main` (ADR-0042). | `--frozen-lockfile` and a lockfile reviewed by the owner; Bun pinned to 1.4.4; installs need the owner's yes. |
| Search and the live site disagree for the minute between the sync and the deployment going live, and after an *Instant Rollback*. | The index is written by the build (ADR-0042). | Roll back with a `git revert` on `main`, which moves both. |
| Visitors take the invented private projects as real, and their links return the 404 (A5). | The owner's decision, ADR-0017. | Replacing the list is a one-file change. |
