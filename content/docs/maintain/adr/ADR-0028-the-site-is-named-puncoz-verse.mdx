## Context

The site has used a working name, *Puncoz Docs*, since it began (`appName` in
`src/lib/shared.ts`). `PRODUCT.md` records that the final name was not chosen and would include
neither the owner's name nor "docs".

On 2026-11-01 the owner chose the name **Puncoz Verse**, as in universe, and asked for it
throughout the project. They named this site's own documentation, the project with the slug
`docs`, **Puncoz Verse Docs**. Earlier the same day they decided that the rename gets its own ADR,
separate from the sidebar (ADR-0027), and mentioned a whole-site universe theme.

Today the one name stands for two things:

- **The site**: the header's wordmark, the home page's and the 404's titles, the Open Graph
  images' site line, through `appName`.
- **This site's own project entry**: the title in `content/docs/meta.json` and
  `content/docs/index.mdx`, shown on its planet card, planet header, sidebar chip and in search.

## Decision

1. **The site is Puncoz Verse.** `appName` becomes *Puncoz Verse*: the header's wordmark on every
   page, the home page's title (*Puncoz Verse — every package and project, documented to the
   version*), the 404's title, the site line of every Open Graph image, and the heading of
   `llms.txt` and `llms-full.txt`'s index, which reads *Docs* today (Fumadocs' default root name).
2. **This site's own docs are Puncoz Verse Docs.** The project with the slug `docs` takes the
   title *Puncoz Verse Docs* in its `meta.json` and overview, so its planet card, planet header,
   sidebar chip, search records and Markdown carry it. Its overview's prose names the site
   *Puncoz Verse*. The slug and every URL stay as they are: `/docs`, `/docs/maintain/…`.
3. **Unchanged identifiers.** The repository folder and `package.json` name
   (`puncoz-packages-docs`), the GitHub link (`puncoz-official/docs`, still undecided in
   `PRODUCT.md`), the Algolia index name and environment variable names stay as they are: they
   are identifiers, not the name readers see, and renaming the repository is outside this
   repository. Approved ADRs keep the name they were written with; they are history.
4. **Every living document follows.** `PRODUCT.md` (the name is chosen; the old rule is removed),
   `DESIGN.md` and its sidecar, `AGENTS.md`, `README.md`, the architecture page, and every app
   flow whose wireframes show the name, with their Archify views.
5. **The universe theme is not part of this ADR.** It waits for its own ADR, ADR-0029, when the
   owner asks for it.

## Options considered

| Concern | Option | Pros | Cons | Verdict |
|---|---|---|---|---|
| Name | *Puncoz Verse* for the site, *Puncoz Verse Docs* for its own project | The owner's choice; the site and its own docs are told apart | Two names to keep in step | Chosen (owner) |
| Identifiers | A — keep the repository, package and GitHub names | Nothing outside the site changes; no broken clones or links | The repository is still called `…-docs` | Chosen |
| Identifiers | B — rename them too | One name everywhere | The GitHub rename is outside this repository and the owner's to do; `package.json` alone changes nothing a reader sees | Rejected |
| Slug of this site's project | A — keep `docs` | Every URL, search record and link keeps working | The slug does not say "verse" | Chosen |
| Slug of this site's project | B — `verse-docs` | Matches the name | Every `/docs/…` URL moves and needs redirects | Rejected |
| Theme | A — rename only; the universe theme in its own ADR | A small, checkable change | Two steps | Chosen |
| Theme | B — rename and theme together | One review | A large change hidden behind a rename | Rejected |

## Consequences

**Positive**

- The site has its chosen name everywhere a reader sees one.
- The site and its own documentation are told apart: *Puncoz Verse* is the whole, *Puncoz Verse
  Docs* is one planet in it.

**Negative / accepted trade-offs**

- The repository and GitHub names keep *docs* until the owner renames them.
- Pages already crawled or shared show the old name until they are fetched again.

## Content invariants

None touched: no page moves and no URL changes. The search index takes the new title on the next
publish (`bun run build`, run by the owner).

## Security considerations

None — this change touches no data, no endpoint and no secret. The name is public text.
