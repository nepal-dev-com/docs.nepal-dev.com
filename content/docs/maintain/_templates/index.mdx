A starting point for each document type. Copy the file into its directory, fill it in, and
delete what does not apply. Each one is a Markdown page with a frontmatter `title`
([ADR-0002](../adr/ADR-0002-living-design-documentation.mdx)) and `description`, a required line
([ADR-0035](../adr/ADR-0035-every-page-is-ready-for-search-and-sharing.mdx)) whose placeholder the build
can't tell from your own, so replace it.

| Template | Copy to |
|---|---|
| [ADR](./adr.mdx) | `adr/ADR-NNNN-kebab-title.mdx` |
| [App flow](./app-flow.mdx) | `app-flow/<feature-slug>.mdx` |
| [PRD](./prd.mdx) | `prd/<feature-slug>.mdx` |
| [Architecture](./architecture.mdx) | `architecture/<area>.mdx` |
| [API](./api.mdx) | `api/<resource>.mdx` |
| [DFD](./dfd.mdx) | `dfd/<feature-slug>.mdx` |
| [Sequence](./sequence.mdx) | `sequence/<flow>.mdx` |
| [State machine](./state.mdx) | `state/<entity>.mdx` |
| [ERD](./erd.mdx) | `erd/system.mdx` |
| [RBAC](./rbac.mdx) | `rbac/<feature-slug>.mdx` |
| [Security](./security.mdx) | `security/<feature-slug>.mdx` |
