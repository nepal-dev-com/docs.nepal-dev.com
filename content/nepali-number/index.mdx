`nepali-number` is a zero-dependency TypeScript library for working with numbers in Nepali
(Devanagari) script. It ships ESM, CommonJS, UMD and IIFE builds with type declarations, so the
same code runs in Node.js, Bun, Deno, bundlers and a plain `<script>` tag.

```ts
import { toNepali, formatNepaliNumber, toNepaliWords, toNepaliCurrency } from "nepali-number"

toNepali(2081)                    // → "२०८१"
formatNepaliNumber(1234567)       // → "१२,३४,५६७"
toNepaliWords(1234567)            // → "बाह्र लाख चौंतीस हजार पाँच सय सतसट्ठी"
toNepaliCurrency(1234567.89)      // → "रू १२,३४,५६७.८९"
```

## What it does

- **Digits both ways**: `0-9` ⇄ `०-९`, in plain numbers or inside any text.
- **Nepali grouping**: `1,23,45,678`, with precision and trailing-zero control.
- **Words**: Nepali cardinals (`एक सय तेईस`), English words with Nepali scales (`twelve lakh`),
  Nepali ordinals (`पाँचौं`) and short forms (`१२ लाख`).
- **Currency**: `रू १२,३४,५६७.८९` as a figure, and rupees and paisa in words
  (`बाह्र रुपैयाँ पचास पैसा`).
- **Utilities**: normalise typed input, detect and validate digit systems, pad and round.
- **Any digits in**: every function reads English, Nepali or mixed digits.
- **Never throws** for its declared input types: invalid input returns a documented default.

It exports 21 named, pure functions and has no runtime dependencies.

## Install

```bash
npm install nepali-number
```
