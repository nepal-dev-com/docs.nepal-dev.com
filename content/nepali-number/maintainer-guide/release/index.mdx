Agents and people never bump the version, tag, edit `CHANGELOG.md` or publish
([`AGENTS.md`](https://github.com/nepal-dev-com/nepali-number-js/blob/main/AGENTS.md) §3). They
propose a Conventional Commit message whose prefix matches the semver impact. release-please turns
those prefixes into the next version and its changelog, in a pull request the owner merges
([ADR-0020](../adr/ADR-0020-release-with-release-please-and-npm-trusted-publishing.mdx)).
