This page is published. It lists names and categories only, never a value.

## Surface

| Surface | State |
|---|---|
| Server Functions | None |
| Route Handlers | None |
| `proxy.ts` | None |
| Forms | None. The contact section builds a `mailto:` link in the browser from the visitor's choices; nothing is sent to the site |
| Content rendered from outside the source tree | None. All copy is JSON in `src/content/`, rendered as text, never as HTML |
| Client Components | Thirteen, listed in [System](../architecture/system.mdx). They receive only the copy they display; none reads storage, cookies or the network. `CopyButton` writes the example message to the clipboard when pressed |
| Outbound links | LinkedIn, GitHub, the blog and one source repository, each with `rel="noopener noreferrer"` |
| Security headers and Content Security Policy | None set by the app |

## Secrets and environment variables

| Variable | Public (`NEXT_PUBLIC_`)? | Used by | Held in |
|---|---|---|---|

The application reads no environment variables. `.env*` files are git-ignored.

## Third parties

Every origin a visitor's browser contacts, or that learns about a visit.

| Third party | What for | What it learns |
|---|---|---|

None at runtime. Geist, Geist Mono, Unbounded and Instrument Serif are fetched from Google Fonts
at build time by `next/font` and served from the site's own origin. A copy of Unbounded Bold,
under the SIL Open Font License, is kept in `src/assets/fonts/` for the share image.

## Install-time scripts

`trustedDependencies` in `package.json` allows lifecycle scripts for `sharp` and
`unrs-resolver`. Both arrived with the scaffold.
